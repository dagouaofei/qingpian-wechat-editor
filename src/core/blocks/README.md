# Blocks 模块

> 状态：占位 · Sprint 1 未实现业务代码

## 职责

承载 **Block 类型定义** 和 block 相关逻辑。

## 约束

- Block 是内容语义，不等于视觉样式
- Block 不应绑定具体样式
- 样式由 Style Assignment / Style Definition 处理

## 核心 Block 类型

title、lead、heading、paragraph、list、quote、highlight、info_card、cta、divider、image_placeholder
