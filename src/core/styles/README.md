# Styles 模块

> 状态：Sprint 3-A · Style System 基础类型与 schema 契约（S3A-STORY-002）

## 职责

承载样式系统能力：

- theme
- style preset
- style variant
- block style registry
- style assignment
- slot、density、layout、spacing、typography、decoration

## 约束

- 样式系统属于 Release 1 核心范围
- Preview 和 Copy 必须共享样式定义
- 不得把样式写死为不可复用的页面样式
