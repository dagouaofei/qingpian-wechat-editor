> **状态：** **PO 手测通过**（2026-06-02）· **不宣称** Release 1 / Sprint 8 粘贴保真已通过

## 1. 测试对象

- 预览页 `/preview` 生成完成后的 **Copy Renderer** 输出（`text/html` + `text/plain`）
- 切换 **基础风格**（经典资讯 / 经典简约）与 **配色**（默认 / 暖色编辑）后的复制结果

## 2. 测试环境

| 项 | 要求 |
|----|------|
| 浏览器 | Chrome / Safari 最新稳定版（任选其一作为主测） |
| 粘贴目标 A | 微信公众号后台编辑器 |
| 粘贴目标 B | 135 编辑器（或同类 HTML 编辑器） |
| 前置 | Volcengine 已配置；完成一篇含 title / lead / paragraph / list / highlight 的文章生成 |

## 3. 手测步骤

1. 首页输入主题 → 生成 → 等待预览完成  
2. 默认风格 + 默认配色 → 点击「复制到公众号」  
3. 粘贴到 **公众号编辑器**，记录标题、导语、列表、强调块样式是否保留  
4. 粘贴到 **135 编辑器**，对比与预览区差异  
5. 切换为 **经典简约** → 再次复制粘贴，确认控件 variant 变化可见  
6. 切换为 **暖色编辑** → 再次复制粘贴，确认 accent / 背景色变化可见
