## 产品澄清结论（2026-06-05）

### 1. `title_plain_minimal` 是否应有卡片边框 / 背景色？

**设计意图（Preview + Copy HTML）：** 应有**轻量**卡片框 — registry `family: cardTitle` · description「cardTitle frame with star icon capsule」· Copy 输出 `h1` padding + `background-color` + `border` 及 icon 胶囊边框/底色。

**`plain` 的含义：** `layoutMode: plain`（居中极简排版节奏），**不等于**「无卡片装饰」。名称中的 minimal 指标题 ornament 层级最轻，不是 typography-only。

### 2. Paste 无卡片边框 / 背景是否算正常？

**对 Release 1 的 `title_plain_minimal` 产品口径：可接受。**

- Copy Renderer **已正确输出**卡片 CSS（见 snapshot）。
- 公众号粘贴后平台常剥离 `h1` 级 inline 背景/边框（与 DRIFT-004/005 同类**平台行为**，但本行 **006C 明确 no effect**，结构无需 renderer 修复）。
- 实机仍保留**标题 typography + 星标 icon 胶囊**时，满足该 variant 的 **typography-first** 交付层级。
- PO 的 WARNING 来自用「卡片框是否与 Preview 一致」作判据；澄清后改判：**已知平台限制 + QA rubric 不匹配**，不是 renderer 缺陷。

### 3. 用户若要可靠「卡片化标题」应选什么？

| 需求 | 推荐 | 说明 |
|------|------|------|
| 左栏 + 竖线 + 可靠粘贴 | `title_left_bar_classic` | 006C/006D 已验证 |
| 独立信息卡片块 | `info_card_*` variants | copy-safe-card pattern · 006D PASS |
| 更强 cardTitle 装饰 | **Sprint 10** catalog（如 `card_bg_icon_corner`） | 不在 S8 扩展 `title_plain_minimal` |

**不应**通过修改 `title_plain_minimal` Copy 结构在 S8 追求 Preview 级卡片保真。
