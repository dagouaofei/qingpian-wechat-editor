# 轻篇产品路线图

> **文档角色：** 轻篇 Release 级产品路线摘要**当前生效事实源**（S12-STORY-008 · **DECISION-123**）。
>
> **Release 2 详细规划：** [`releases/release-2/plan.md`](releases/release-2/plan.md)

**说明：** R3+ 仅为候选路线，**不构成当前承诺**。

---

## 路线图总览

```text
Release 1（进行中 · 未关闭）
  → 单篇公众号生成、排版、复制一致性、样式治理、上线基础

Release 2（Planned / Candidate / Not Started）
  → 品牌 / 项目驱动的 AI 内容工作台最小闭环

Release 3+（候选 · 非承诺）
  → 更完整内容运营、多平台、多模态、协作与商业化
```

## Release 2

| 项           | 内容                                                       |
| ------------ | ---------------------------------------------------------- |
| **状态**     | **Planned / Candidate / Not Started**                      |
| **定位**     | 品牌 / 项目驱动的 AI 内容工作台最小闭环                    |
| **Outcome**  | 验证最小内容运营闭环 + 双入口（简单 + 工作台）             |
| **验证对象** | 鲁老师项目（主）· 秒篇 AIPPT（辅）                         |
| **事实源**   | [`releases/release-2/plan.md`](releases/release-2/plan.md) |

**最小闭环：**

```text
品牌资料 → 灵感 → 选题 → 成稿 → 排版复制 → 内容资产 → 手动复盘 → 反哺选题
```

**继承 R1：** 生成 · 预览 · 排版 · 复制 · 样式治理

**尚未启动：** Release 2 及 R2 Sprint 均需 PO 明确批准后方可启动。

## Release 3+（候选 · 非承诺）

以下方向进入完整产品愿景与 Story Map，**不构成当前 Release 承诺**：

| 候选方向         | 说明                              |
| ---------------- | --------------------------------- |
| 持续内容运营全量 | 栏目、系列、内容计划、多账号运营  |
| 多平台适配与分发 | 抖音、小红书、LinkedIn 等完整适配 |
| 多模态内容       | 视频脚本、图文混合、AI 生图       |
| 协作与权限       | 多成员、审批、团队协作            |
| 数据自动化       | 平台数据自动同步、自动复盘        |
| 商业化           | 公开 SaaS、付费、订阅             |
| 受众洞察全量     | M11 完整互动运营                  |

详见 [`../product/user-story-map.md`](../product/user-story-map.md) Slice 4–7 · PBI-QP-004/010。
