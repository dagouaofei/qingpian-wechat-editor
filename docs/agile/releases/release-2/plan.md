# Release 2 Plan

> **文档角色：** Release 2 候选规划、Outcome Goal、Scope 边界与渐进式迭代方向的**当前生效事实源**（S12-STORY-008 · **DECISION-123**）。
>
> **配套文档：** [`backlog.md`](backlog.md) · [`coverage.md`](coverage.md) · [`../../product-roadmap.md`](../../product-roadmap.md)

**重要说明：**

- Release 2 **尚未启动**；本文件为候选规划，不代表 PO 已批准启动 Release 2 或任何 R2 Sprint。
- **不关闭** Release 1；**不关闭** Sprint 12。
- **不为**鲁老师项目或秒篇 AIPPT 做项目定制功能；R2 做通用工作台能力，以双项目为验证对象。

---

## 1. Release 2 定位

**一句话定位：**

> Release 2 是「品牌 / 项目驱动的 AI 内容工作台最小闭环」，但产品入口必须兼顾新用户和小白用户：先能简单写文章，再逐步沉淀品牌、灵感、选题、资产和复盘。

**主线定位（PO 已确认）：**

```text
品牌 / 项目驱动的最小内容工作台。
```

不是继续只做公众号单篇成稿工具，也不是直接做完整内容营销平台。

---

## 2. Outcome Goal

验证轻篇是否能在**不增加新用户理解负担**的前提下，帮助高频内容生产者围绕一个品牌或项目，完成从快速写文章到品牌资料、灵感、选题、成稿、排版复制、内容资产和手动复盘的最小内容运营闭环，并提升效率、品牌贴合度、可发布质量和持续使用意愿。

---

## 3. 验证方式与验证对象

### 3.1 验证方式（PO 已确认）

```text
内部真实运营优先。
```

R2 先通过真实项目验证，而不是先抽象做通用 SaaS。

### 3.2 验证对象（PO 已确认）

| 角色           | 项目       | 说明                 |
| -------------- | ---------- | -------------------- |
| **主验证对象** | 鲁老师项目 | 高频内容运营真实场景 |
| **辅验证对象** | 秒篇 AIPPT | 品牌内容持续生产场景 |

**约束：**

```text
R2 做通用工作台能力，不为鲁老师或秒篇 AIPPT 做定制功能。
```

---

## 4. 最小成功闭环（PO 已确认）

```text
品牌资料
→ 灵感
→ 选题
→ 成稿
→ 排版复制
→ 内容资产
→ 手动复盘
→ 反哺下一轮选题
```

**边界约束：**

| 能力     | R2 边界                          |
| -------- | -------------------------------- |
| 灵感池   | 只做记录、归属、转选题           |
| 内容资产 | 只保存已生成文章、项目归属、标签 |
| 复盘     | 只做手动记录，不做自动数据同步   |

---

## 5. R1 继承关系（PO 已确认）

```text
复用 R1 生成、预览、排版、复制能力；
改造生成入口，接入品牌 / 灵感 / 选题 / 创作任务上下文；
同时保留低门槛「快速写文章」入口。
```

**关键体验约束：**

```text
品牌资料、灵感、选题、创作任务是增强上下文，不是新用户强制前置条件。
```

详见 [`../../release-1-capability-coverage.md`](../../release-1-capability-coverage.md)。

---

## 6. Must / Should / Could / Won't

详细条目见 [`backlog.md`](backlog.md)。

**摘要：**

- **Must：** 快速写文章入口 · 品牌/项目资料 · 品牌上下文生成 · 灵感 · 选题 · 创作任务 · 复用 R1 排版复制 · 内容资产 · 手动复盘 · 双入口并存
- **Should：** 灵感→选题建议 · 选题→大纲建议 · 复盘→下一轮建议 · 品牌视觉偏好基础记录
- **Could：** 高表现拆解最小实验 · 标签增强 · 多平台改写雏形
- **Won't：** CRM · 自动发布 · 完整多平台分发 · 完整团队协作 · 公开 SaaS 商业化闭环等

**必须明确：**

- **PBI-QP-009** 不自动升 P0；高表现内容拆解与再创作仅作为 Could / 条件触发
- 栏目 / 系列 / 内容计划后置，**不进入 R2 Must**

---

## 7. 新用户 / 小白用户入口约束

| 入口类型       | 说明                                         |
| -------------- | -------------------------------------------- |
| **简单入口**   | 低门槛快速写文章；不要求先建品牌/灵感/选题   |
| **工作台入口** | 品牌/项目上下文；灵感→选题→任务→成稿完整链路 |

两者**并存**；工作台能力为增强上下文，非强制前置。

---

## 8. 成功指标

| 维度       | 指标                                      |
| ---------- | ----------------------------------------- |
| 使用频率   | PO 及验证对象是否每周实际使用轻篇生产内容 |
| 闭环完成   | 能否从品牌/灵感到公众号成稿跑通最小闭环   |
| 成稿质量   | 是否达到可发布标准                        |
| 效率       | 是否比手工写作和排版明显省时              |
| 品牌贴合度 | 品牌资料是否提升生成内容贴合度            |
| 复制稳定性 | 复制到公众号是否保持样式（继承 R1）       |
| 资产复用   | 历史文章是否可查找、可复用                |
| 复盘反馈   | 手动复盘是否影响下一轮选题                |
| 新用户门槛 | 小白用户能否不建工作台直接快速成稿        |

来源：[`../../../product/product-success-model.md`](../../../product/product-success-model.md) · H01–H10

## 9. 失败信号

| 维度       | 失败信号                                |
| ---------- | --------------------------------------- |
| 使用意愿   | 验证对象不用或只偶尔用                  |
| 新用户门槛 | 强制工作台前置导致小白用户无法快速成稿  |
| 品牌贴合   | 有品牌资料仍明显不贴合                  |
| 复制稳定性 | 复制到公众号后样式丢失（R1 能力退化）   |
| 闭环断裂   | 无法从灵感到资产到复盘形成循环          |
| 范围膨胀   | R2 滑向完整 CRM / 自动发布 / 多平台分发 |
| 定制陷阱   | 为单一验证项目做不可复用定制功能        |

## 10. 渐进式 Sprint 候选顺序

> **这不是正式 Sprint Plan**；不代表 Release 2 已启动；每个 R2 Sprint 启动前仍需正式 Sprint Planning 和 Product Owner Approved。

| 阶段         | 候选 Sprint  | 目标摘要                               |
| ------------ | ------------ | -------------------------------------- |
| **第一阶段** | R2-Sprint-01 | 简单入口 + 品牌上下文生成              |
| **第二阶段** | R2-Sprint-02 | 项目 / 品牌工作台 + 灵感 / 选题 / 任务 |
| **第三阶段** | R2-Sprint-03 | 内容资产 + 手动复盘                    |

## 11. 与 R1 / R3+ 的边界

| Release | 定位摘要                                                   |
| ------- | ---------------------------------------------------------- |
| **R1**  | 单篇公众号生成、排版、复制一致性、样式治理、上线基础       |
| **R2**  | 品牌 / 项目驱动的 AI 内容工作台最小闭环                    |
| **R3+** | 更完整内容运营、多平台、多模态、协作与商业化候选（非承诺） |

R2 **不关闭** R1；R2 **不启动** R3+ 范围。
