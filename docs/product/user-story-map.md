# 用户故事地图

> 轻篇公众号排版 · qingpian-wechat-editor

## 主干流程

```
准备内容 → 发起生成 → 生成文章 → 自动排版 → 预览检查 → 调整优化 → 复制到公众号 → 发布前检查
```

## Release 1 · P0 用户故事

### 准备内容 & 发起生成

| ID | 用户故事 | 优先级 |
|----|----------|--------|
| US-R1-001 | 用户可以输入主题并发起生成 | P0 |
| US-R1-002 | 用户可以粘贴资料并发起生成 | P0 |
| US-R1-003 | 用户可以粘贴草稿并发起优化排版 | P0 |

### 生成 & 结构化

| ID | 用户故事 | 优先级 |
|----|----------|--------|
| US-R1-004 | 用户可以看到生成进度（流式 / 打字机式展示） | P0 |
| US-R1-005 | 用户可以获得包含标题、导语、小标题、正文、重点内容、列表、信息卡片、总结和 CTA 的完整文章 | P0 |
| US-R1-006 | 系统生成结果必须进入统一 Article Schema | P0 |

### 排版 & 预览

| ID | 用户故事 | 优先级 |
|----|----------|--------|
| US-R1-007 | 用户可以看到自动排版后的文章预览 | P0 |
| US-R1-008 | 用户可以看到配图位置建议（image_placeholder） | P0 |

### 复制 & 质量保障

| ID | 用户故事 | 优先级 |
|----|----------|--------|
| US-R1-009 | 用户可以一键复制微信兼容 HTML | P0 |
| US-R1-010 | 粘贴到微信公众号编辑器后基础样式基本一致 | P0 |
| US-R1-011 | 产品团队可以通过固定 fixture 和人工粘贴测试验证复制效果 | P0 |

## 后续 Release 用户故事（占位）

- Release 3：资料增强、智能配图
- Release 4：样式导入、品牌样式库
