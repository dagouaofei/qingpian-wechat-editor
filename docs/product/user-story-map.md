## 1. Story 背景与目标

**S12-STORY-004** 的目标是将 **S12-STORY-003** 的产品模块树，转化为以用户任务为中心的完整 User Story Map，明确轻篇目标用户如何围绕一个品牌持续生产内容，并建立 Release 2 及后续迭代所需的产品成功验证机制。

### 1.1 本 Story 回答的问题

- 目标用户如何围绕一个品牌持续生产内容？
- 从最初建立品牌资料，到灵感、选题、创作、编辑、排版、发布、资产沉淀、复盘反馈，完整路径是什么？
- 哪些路径可以形成 Release 2 的最小成功闭环候选？
- 哪些路径用于后续商业成功验证？

### 1.2 本 Story 明确不做

- 不决定 Release 2 最终范围；
- 不直接生成 Product Backlog 全量条目；
- 不把所有用户任务拆成开发 Story；
- 不开发产品代码；
- 不决定技术实现；
- 不启动 S12-STORY-005；
- 不承诺所有 Story Map 项目都会开发。

## 2. Story Map 设计原则

### 2.1 按用户旅程，不按模块

**错误方式：**

```text
M01 品牌中心
M02 灵感中心
M03 内容计划
M04 内容创作
……
```

**正确方式：**

```text
我想持续运营一个品牌
→ 我建立品牌内容基础
→ 我收集灵感和外部信号
→ 我形成选题和计划
→ 我持续生产系列内容
→ 我完成单篇创作
→ 我排版发布
→ 我沉淀资产
→ 我复盘反馈
→ 我调整下一轮内容
```

> **模块是后台能力，Story Map 是用户完成任务的路径。**

### 2.2 以持续内容生产为中心

轻篇不是单篇文章生成器，而是面向高频内容生产者的 **AI 内容营销工作台**。

必须显性覆盖：

```text
持续生产
系列化生产
历史复用
多轮迭代
复盘反哺
```

### 2.3 以商业成功验证为中心

每个 Release 不只问功能是否完成，还要问用户是否真的愿意持续使用、是否更省时、内容是否可发布、资产是否越用越有价值、反馈是否能影响下一轮 Backlog。

## 4. 用户活动与任务拆解

### A01 建立品牌与内容基础

**用户任务：**

- 创建一个品牌空间；
- 填写品牌定位；
- 录入目标用户；
- 录入产品 / 服务资料；
- 录入案例、FAQ、专业知识；
- 设置品牌表达规范；
- 设置品牌视觉偏好；
- 导入外部资料；
- 从历史文章中提炼品牌知识；
- 区分不同品牌资料，避免混用。

**对应模块：** M01 品牌与知识中心 · M10 工作空间与协作 · M08 内容资产中心

---

### A02 收集灵感与外部信号

**用户任务：**

- 快速记录自己的内容想法；
- 收藏公众号文章；
- 收藏网页、视频、小红书、知乎等外部内容；
- 订阅或关注竞品账号；
- 收集行业热点和用户问题；
- 收集 AI 搜索 / GEO 问题；
- 提取文章主题、关键词、观点和结构；
- 对高表现内容进行拆解；
- 从竞品内容中识别可借鉴模式；
- 将灵感归类、打标签和去重。

**高表现内容拆解与再创作：**

```text
看到已经验证过的好内容
→ 拆解选题、标题、结构、表达和传播点
→ 结合自己的品牌、案例、观点再创作
→ 快速形成自己的内容版本
```

**边界：**

- 支持借鉴内容模式和表达结构；
- 不鼓励直接搬运、洗稿或高度近似复制；
- 优先级由 Product Owner 自己运营工作是否强需要决定。

**对应模块：** M02 灵感中心 · M04 内容创作中心 · M05 内容编辑与质量控制 · M08 内容资产中心

---

### A03 形成选题与内容计划

**用户任务：**

- 将灵感转为候选选题；
- 手动创建选题；
- AI 生成选题角度；
- 评估选题价值；
- 判断选题是否适合当前品牌；
- 给选题排序；
- 规划栏目；
- 规划系列文章；
- 安排周计划 / 月计划；
- 将选题变成内容任务；
- 关联资料、案例和参考内容；
- 标记任务状态。

**对应模块：** M03 内容计划 · M02 灵感中心 · M01 品牌与知识中心

---

### A04 持续内容运营与系列化生产

**用户任务：**

- 围绕一个品牌长期规划内容方向；
- 建立固定栏目；
- 建立系列主题；
- 将一个主题拆成多篇内容；
- 将一篇内容改编成多个平台版本；
- 复用历史文章、案例和片段；
- 持续补齐内容空白；
- 根据上一轮表现调整下一轮计划；
- 批量生产同一主题下的多篇内容；
- 为不同品牌维持不同内容节奏。

> **这一活动是轻篇区别于单篇生成工具的关键。**

**对应模块：** M03 内容计划 · M04 内容创作中心 · M08 内容资产中心 · M09 数据分析与内容复盘 · M11 受众洞察与互动运营

---

### A05 准备单篇创作任务

**用户任务：**

- 选择一个选题；
- 明确目标用户；
- 明确内容目标；
- 选择发布平台；
- 选择文章类型；
- 关联品牌知识；
- 关联灵感和外部资料；
- 关联历史内容；
- 生成创作 brief；
- 明确写作约束和禁区。

**对应模块：** M03 内容计划 · M04 内容创作中心 · M01 品牌与知识中心 · M02 灵感中心 · M08 内容资产中心

---

### A06 生成内容初稿

**用户任务：**

- 生成大纲；
- 修改大纲；
- 生成标题；
- 生成小标题；
- 生成正文初稿；
- 基于品牌知识生成；
- 基于外部资料生成；
- 基于案例生成；
- 基于高表现内容拆解结果再创作；
- 生成多版本；
- 生成公众号文章；
- 生成口播稿；
- 生成短视频脚本；
- 生成多平台基础版本；
- 查看生成依据。

**对应模块：** M04 内容创作中心 · M01 品牌与知识中心 · M02 灵感中心 · M08 内容资产中心

---

### A07 编辑与质量控制

**用户任务：**

- 编辑全文；
- 段落级改写；
- 降低 AI 味；
- 补充案例；
- 删除空洞内容；
- 重组结构；
- 优化标题和小标题；
- 检查品牌一致性；
- 检查逻辑；
- 检查事实和引用；
- 检查过期信息；
- 检查相似度和版权风险；
- 做 SEO / GEO 优化；
- 做发布前审校。

**对应模块：** M05 内容编辑与质量控制 · M01 品牌与知识中心 · M02 灵感中心

---

### A08 排版与视觉优化

**用户任务：**

- 选择文章排版主题；
- 匹配品牌视觉风格；
- 自动匹配标题、正文、引用、列表、卡片样式；
- 查看多套样式方案；
- 手动替换局部样式；
- 调整视觉密度；
- 选择或生成配图建议；
- 检查排版是否专业；
- 检查是否适合公众号；
- 保存常用样式；
- 将用户调整沉淀为品牌样式。

**对应模块：** M06 排版与视觉中心 · M01 品牌与知识中心 · M07 平台适配、发布与分发

---

### A09 平台适配与发布

**用户任务：**

- 生成公众号可复制内容；
- 检查 Preview / Copy 一致性；
- 一键复制到公众号；
- 处理图片和链接；
- 生成公众号发布前检查清单；
- 转成小红书版本；
- 转成知乎版本；
- 转成抖音口播稿或脚本文案包；
- 记录发布平台、账号、时间和链接；
- 管理同一内容的多平台版本。

**对应模块：** M07 平台适配、发布与分发 · M08 内容资产中心 · M09 数据分析与内容复盘

---

### A10 沉淀内容资产

**用户任务：**

- 保存草稿；
- 保存成品文章；
- 保存已发布版本；
- 保存多平台版本；
- 保存历史文章；
- 保存可复用片段；
- 保存案例、金句、CTA；
- 管理素材；
- 给内容打标签；
- 搜索历史内容；
- 识别相似内容；
- 推荐可复用历史内容；
- 将高表现内容转为资产。

**对应模块：** M08 内容资产中心 · M01 品牌与知识中心 · M09 数据分析与内容复盘

---

### A11 复盘与反馈迭代

**用户任务：**

- 记录发布数据；
- 记录阅读、点赞、收藏、评论、转发、咨询等结果；
- 分析单篇表现；
- 分析选题表现；
- 分析栏目表现；
- 分析高表现内容；
- 分析低表现内容；
- 记录复盘结论；
- 收集用户评论和问题；
- 将用户问题转为灵感；
- 将复盘结论反哺内容计划；
- 将有效表达和用户反馈反哺品牌知识；
- 决定下一轮写什么。

**对应模块：** M09 数据分析与内容复盘 · M11 受众洞察与互动运营 · M02 灵感中心 · M03 内容计划 · M01 品牌与知识中心

## 5. Story Map 切片候选

以下 Slice 为**候选**，不是 Release 2 承诺。

### Slice 1：单篇公众号可用闭环

**目标：** 从一个选题生成一篇可复制到公众号的成稿。

**覆盖活动：** A05 → A06 → A07 → A08 → A09

**适用：** Release 1 已部分覆盖，Release 2 可继续增强。

### Slice 2：品牌驱动内容生产闭环

**目标：** 围绕一个品牌，用品牌资料和知识生成更贴合品牌的内容。

**覆盖活动：** A01 → A05 → A06 → A07 → A08 → A09

**适用：** Release 2 最小成功闭环候选。

### Slice 3：灵感到选题到成稿闭环

**目标：** 从灵感或外部文章出发，形成自己的选题和文章。

**覆盖活动：** A02 → A03 → A05 → A06 → A07 → A08 → A09

**适用：** Release 2 核心候选。

### Slice 4：高表现内容拆解与再创作闭环

**目标：** 看到一篇高表现内容后，拆解其模式，并结合自己的品牌再创作。

**覆盖活动：** A02 → A03 → A05 → A06 → A07

**适用：** 候选优先级取决于 Product Owner 自己运营工作是否强需要。

### Slice 5：持续内容运营闭环

**目标：** 围绕一个品牌持续规划和生产内容，而不是只写单篇文章。

**覆盖活动：** A01 → A02 → A03 → A04 → A05 → A06 → A07 → A08 → A09 → A10 → A11

**适用：** 轻篇长期核心方向。

### Slice 6：内容资产复用闭环

**目标：** 让历史文章、案例、片段和素材持续产生价值。

**覆盖活动：** A08 → A09 → A10 → A05 → A06

**适用：** Release 2 或 Release 3 候选。

### Slice 7：复盘反馈驱动下一轮内容

**目标：** 用内容表现和用户反馈决定下一轮写什么。

**覆盖活动：** A09 → A10 → A11 → A02 → A03

**适用：** Release 2 可做轻量版，完整数据自动化后置。

## 6. Release 2 最小成功闭环候选

```text
品牌资料
→ 灵感记录
→ 选题
→ 创作任务
→ 文章生成
→ 编辑优化
→ 公众号排版
→ 复制发布
→ 内容资产保存
→ 手动复盘
```

**核心目标：** 让 Product Owner 自己可以围绕一个品牌，高频、稳定地产出可发布公众号文章。

**优先验证对象（Product Owner 自己的运营工作）：**

- 秒篇 AIPPT 内容；
- AI 论文内容；
- SEO / GEO 内容；
- 鲁老师项目内容；
- 其他需要持续运营的品牌内容。

> **S12-STORY-004 不最终决定 Release 2 范围。** Release 2 最终范围由 **S12-STORY-008** 决定。
