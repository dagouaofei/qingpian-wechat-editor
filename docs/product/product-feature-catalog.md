# 轻篇产品功能目录

> **文档角色：** 轻篇产品功能目录口径、字段标准、各模块功能重点与 M06 样式逻辑的**当前生效事实源**（S12-STORY-003 · **DECISION-118**）。
>
> **配套文档：** [`product-module-tree.md`](product-module-tree.md) — 一级模块树、候选二级模块与模块边界

---

## 1. 功能目录定位

**S12-STORY-003** 的目标是将 S12-STORY-002 已确认的产品愿景、目标用户、核心场景与系统边界，进一步整理为完整产品模块树与产品功能目录，为后续 User Story Map、Product Backlog、Release Planning 和 Sprint Planning 提供稳定输入。

### 1.1 核心原则

```text
功能目录 = 全景地图
Release Backlog = 当前阶段取舍
Sprint Backlog = 本轮执行承诺
```

- **功能目录不是开发计划**；不得将本文档中的功能项直接等同于 Sprint 或 Release 承诺。
- 一级模块按用户任务划分；二级模块与功能归属**可调整**。
- 实施顺序由后续 Release 与 Sprint 规划决定。

### 1.2 本 Story 明确不做

- 不决定 Release 2 具体范围；
- 不决定各模块开发优先级；
- 不把全部功能拆成开发 Story；
- 不承诺所有功能在同一 Release 或 Sprint 实现；
- 不开发产品代码；
- 不设计具体数据库、接口或技术架构；
- 不启动 S12-STORY-004；
- 不替代后续 User Story Map、Product Backlog 和 Release Planning。

---

## 2. 功能目录字段标准

完整功能条目可采用以下字段；本 Story 以「模块功能重点 + 最小核心 + 边界」为主，不要求一次性展开为所有字段的完整表格。

| 字段       | 说明                                   |
| ---------- | -------------------------------------- |
| 功能 ID    | 例如 `M01-F001`                        |
| 一级模块   | 所属一级产品模块                       |
| 二级模块   | 当前候选归属，可调整                   |
| 功能名称   | 用户可感知功能                         |
| 功能说明   | 做什么                                 |
| 用户价值   | 为什么需要                             |
| 适用场景   | 对应核心场景                           |
| 内容形态   | 文字 / 图片 / 音频 / 视频 / 多模态     |
| 平台范围   | 公众号 / 抖音 / 小红书 / 知乎 / 多平台 |
| 能力状态   | 已实现 / 已确认方向 / 候选 / 待研究    |
| 优先级判断 | 暂高 / 暂中 / 暂低 / 待定              |
| 事实来源   | 用户决策 / 现有代码 / 历史文档 / 推断  |
| 备注       | 风险、边界和依赖                       |

---

## 3. 当前优先级说明（非开发承诺）

- 「暂高、暂中、暂低」仅为当前粗略判断，**不构成** Release 或 Sprint 承诺。
- **M11** 受众洞察与互动运营已纳入完整产品范围，**当前预估优先级靠后**。
- **C01** 多模态媒体制作中心为候选一级模块，**当前预估优先级靠后**。
- **M03-09** 营销活动与内容项目归入 M03，**当前预估优先级靠后**。
- 抖音相关能力已纳入完整产品方向，**不设**独立抖音一级模块。
- SEO、GEO、AI、自动化作为功能方向或横向能力（X01 等），**不单独设**一级模块。

## 4. M01 品牌与知识中心

**功能重点：** 品牌档案 · 目标用户与用户问题 · 品牌内容策略 · 表达规范 · 产品/服务/业务知识 · 外部资料与事实库 · 知识导入整理 · 检索引用 · 版本维护 · 多品牌隔离

**最小核心（Release Planning 参考，非当前开发承诺）：**

```text
品牌空间
→ 品牌档案
→ 目标用户
→ 产品 / 服务资料
→ 案例与 FAQ
→ 外部资料导入
→ AI 写作时调用
→ 多品牌隔离
```

**边界：** 正式事实源为品牌规则与知识；**不存放**已发布的文章成品（见 M08）。

---

## 5. M02 灵感中心

**功能重点：** 跨平台竞品账号订阅与监控 · 内容采集收藏 · 解析提取 · 整理检索 · 热点趋势与内容空白 · 灵感聚合 · 灵感转选题

> 原「竞品公众号订阅」升级为**「跨平台竞品账号订阅与监控」**。公众号是当前优先渠道，后续可扩展至抖音、小红书、知乎、视频号等平台。

**最小核心：**

```text
灵感快速记录
→ 链接 / 文章收藏
→ 内容主题、关键词、观点提取
→ 标签分类与来源追踪
→ 灵感转选题
→ 加入内容计划
```

**边界：** 存放**候选内容机会**；正式选题与排期事实源在 **M03**。

---

## 6. M03 内容计划

**功能重点：** 选题池 · 评估与优先级 · 栏目系列 · 内容策略与阶段目标 · 日历排期 · 内容任务 · 执行跟踪 · AI 计划助手 · 营销活动与内容项目（暂低）

**最小核心：**

```text
选题池
→ 选题评价与优先级
→ 栏目 / 系列规划
→ 周月内容计划
→ 内容任务创建
→ 任务资料关联
→ 任务状态管理
```

**边界：** 与 M02 职责分离 — M03 管理**已决定的**选题、计划与任务。

---

## 7. M04 内容创作中心

**功能重点：** 创作任务工作台 · 大纲结构 · AI 初稿 · 标题与关键内容 · 多来源融合 · 品牌化生成 · 系列化创作 · 多模态与多平台初稿（含视频转文章、文章转脚本等）

**最小核心：**

```text
创作任务工作台
→ 创作 brief
→ 大纲生成与编辑
→ AI 初稿生成
→ 品牌知识调用
→ 多来源资料融合
→ 标题 / 小标题 / CTA 生成
→ 生成依据展示
```

**边界：** 负责从 0 到 1 的生成；深度编辑与质量控制见 **M05**。

---

## 8. M05 内容编辑与质量控制

**功能重点：** 结构化编辑器 · 改写优化 · 结构逻辑 · 品牌一致性 · 事实引用 · 合规风险 · SEO/GEO · 版本审校

**最小核心：**

```text
结构化内容编辑器
→ 段落级 AI 编辑
→ 全文改写
→ 降低 AI 味
→ 结构重组
→ 标题 / 小标题优化
→ 品牌一致性检查
→ 逻辑与空洞内容检查
→ 发布前审校清单
```

**边界：** 不负责样式视觉匹配（M06）与平台复制发布（M07）。

---

## 9. M06 排版与视觉中心

**功能重点：** 文章编排 · 主题模板样式 · 组件与 Variant · 自动样式匹配 · 图片图表 · 预览调整 · 样式资产 · 视觉质量治理 · 样式来源 · 样式匹配引擎

**最小核心：**

```text
内容层级识别
→ 自动样式匹配
→ 标题 / 正文 / 引用 / 列表 / 卡片样式
→ 样式预览
→ 样式替换
→ 样式库与 Variant 管理
→ 样式质量状态
→ 视觉质量检查
```

### 9.1 样式来源完整链路

```text
人工设计
+ 外部采集
+ AI 生成
+ 品牌规则
+ 内容结构
+ 用户自定义
+ 数据反馈优化
→ 样式库 / 模板库 / Variant 库
→ 用户侧智能匹配和组合
```

**至少包括：**

- 人工设计样式入库；
- 外部样式采集入库；
- AI 样式生成；
- 品牌视觉规则驱动样式；
- 内容结构驱动样式组合；
- 用户自定义样式沉淀；
- 样式表现反馈与优化。

### 9.2 样式匹配完整逻辑

样式匹配必须综合：

- 品牌匹配；
- 内容匹配；
- 平台匹配；
- 用户偏好匹配；
- 质量匹配；
- 组合匹配；
- 数据反馈匹配；
- 人工可控。

**至少包括：**

- 样式匹配规则引擎；
- 样式匹配评分与排序；
- 品牌约束匹配；
- 内容类型与结构匹配；
- 平台兼容约束匹配；
- 用户偏好与历史选择匹配；
- 样式组合冲突检查；
- 样式推荐解释；
- 手动覆盖与二次调整；
- 匹配效果反馈学习。

### 9.3 M06 与 M07 边界

```text
M06 负责：好不好看、是否专业、是否符合品牌视觉。
M07 负责：能不能可靠复制、导出、发布到平台，并在平台中保持一致。
```

**边界：** 模板、样式和 Variant 的正式事实源在 **M06**。

## 10. M07 平台适配、发布与分发

**功能重点：** 平台账号渠道 · 微信公众号适配 · 发布前检查 · 复制导出与内容包 · 自动/半自动发布 · 多平台转换 · 多平台分发 · 平台版本管理

**当前关键链路（公众号 · Release 1 已部分验证）：**

```text
微信安全 CSS
→ Preview / Copy 一致
→ Copy HTML
→ Clipboard
→ Paste QA
→ 发布前检查
```

**边界：** 平台账号、发布配置和发布结果的正式事实源在 **M07**；视觉样式定义在 **M06**。

## 11. M08 内容资产中心

**功能重点：** 内容库 · 文章版本 · 栏目专题系列归档 · 片段素材复用 · 检索组织 · 相似重复识别 · 历史再加工 · 复用建议

**最小核心：**

```text
内容库
→ 草稿 / 成品 / 已发布状态
→ 品牌内容归档
→ 内容搜索与标签
→ 内容来源追踪
→ 历史文章导入
→ 内容关联
→ 内容复用建议
```

**边界：** 存放**已生产的内容成果**；品牌知识与规则见 **M01**。

**最小核心：**

```text
发布记录
→ 手动数据录入
→ 单篇内容分析
→ 选题表现分析
→ 高表现内容识别
→ 内容复盘记录
→ 选题优化建议
→ 复盘反哺内容计划
```

**边界：** 内容表现数据与复盘记录的正式事实源在 **M09**；受众互动洞察见 **M11**。

**最小核心：**

```text
个人工作空间
→ 多品牌管理入口
→ 品牌数据隔离
→ 个人偏好设置
→ 基础账号安全
→ 管理员后台
```

## 14. M11 受众洞察与互动运营

**功能重点：** 互动信息接入 · 用户问题整理 · 受众洞察 · 互动运营 · 反馈转化 · 互动效果复盘

**最小核心：**

```text
手动录入用户反馈
→ 用户问题提取

→ 用户问题转灵感 / 选题

```

**边界：** 受众反馈与互动洞察的正式事实源在 **M11**；已纳入完整产品范围，**当前预估优先级靠后**。
