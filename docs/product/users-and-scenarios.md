# 目标用户与核心场景

> **文档角色：** 轻篇目标用户层次、核心场景与信息来源优先级的**当前生效事实源**（S12-STORY-002 · **DECISION-117**）。  
> **产品愿景、完整范围与系统边界：** 见 [`product-vision.md`](product-vision.md)。

## 1. 内部核心用户

当前操作者为 **Product Owner 本人**，用于多个自有业务及试点品牌的**高频内容生产**。

## 2. 内部试点品牌与联合设计对象

典型为**鲁老师**，主要提供：

- 品牌目标；
- 专业知识；
- 目标受众；
- 内容方向；
- 真实运营反馈。

试点品牌方**不一定直接操作产品**。

**鲁老师案例定位：**

- 内部试点品牌；
- 联合设计对象；
- 品牌长期内容运营的真实验证案例。

**不是**独立的「代运营产品方向」或「代运营管理系统」验证对象。

## 3. 首要商业用户

**高频自媒体作者** — 以持续内容运营为核心，而非偶发单篇需求。

## 4. 次要商业用户

- 小企业老板；
- 个人创业者。

## 5. 非优先用户

只有**偶发单篇生成**需求、**没有长期内容运营需求**的低频用户。

## 6. 核心用户问题

高频内容生产者在长期品牌内容运营中普遍面临：

- 不知道「有什么值得写」；
- 难以将外部信号与内部想法转化为可执行的选题与计划；
- 内容生产门槛高，难以稳定产出发布级成品；
- 排版与平台适配耗时，影响发布效率与一致性；
- 内容资产分散，难以复用与复盘；
- 缺少从数据反馈回到选题与计划的闭环。

轻篇以**高频、品牌、长期**内容运营为优先解决方向。

## 7. 五个核心场景

### 场景一：围绕品牌进行长期内容运营

支持**自营品牌**和**受托运营品牌**的内容运营。

- 产品中心是**品牌内容运营**，**不是**代运营公司管理系统；
- 单个运营者可服务多个品牌，但不扩展为合同、收费、回款或 CRM 能力。

### 场景二：从外部信号和内部想法形成灵感、选题和内容计划

主要流程：

```text
外部内容或内部想法
→ 进入灵感中心
→ 筛选并转化为选题
→ 加入内容计划
→ 排期和执行
```

灵感中心与内容计划为**独立能力域**（见 `product-vision.md` §6.2 · §6.3）。

### 场景三：从选题和资料生成公众号成品文章

成功标准是形成**内容和排版均达到发布要求**的公众号文章，**而不只是生成文本**。

（与当前 `qingpian-wechat-editor` Release 1 主链路直接相关。）

### 场景四：加工已有文章并完成专业排版与平台适配

支持输入形态包括：文本 · Markdown · 网页 · HTML · 历史文章 · 文档等。

### 场景五：系列化、高频生产并持续沉淀内容资产

围绕品牌、栏目、系列和业务目标持续生产、复用和优化内容。

**不得**将「运营者代客户生产内容」单独列为第六核心场景；该能力已包含在场景一与协作支持中，产品定位仍为非代运营管理系统。

## 8. 外部信息来源优先顺序

在灵感与选题形成阶段，外部信息按以下**优先顺序**参考（非实施优先级）：

1. 与品牌直接相关的内部资料与品牌知识；
2. 竞品与对标账号 / 公众号内容；
3. 用户收藏的文章、网页与链接；
4. 行业热点、新闻与搜索关键词；
5. 小红书、抖音、知乎等平台公开内容；
6. 通用搜索引擎与网页；
7. GEO、AI 搜索与专业行业数据源；
8. 历史高表现内容与 AI 识别的内容空白。

## 9. 鲁老师案例的正确定位

| 维度     | 定位                                       |
| -------- | ------------------------------------------ |
| 角色     | 内部试点品牌 + 联合设计对象                |
| 验证目标 | 品牌长期内容运营闭环（非代运营 SaaS）      |
| 输入     | 品牌目标、专业知识、受众、方向、运营反馈   |
| 操作方式 | 可由 PO / 运营者代操作；品牌方可不直接登录 |
| 非定位   | 独立代运营产品方向 · 代运营公司经营系统    |

## 10. 多品牌能力与代运营管理系统的边界

**轻篇支持：**

- 单个运营者管理**多个品牌**；
- 品牌级知识、灵感、计划、资产与数据的**隔离**；
- 必要的协作、审批与操作记录（见 `product-vision.md` §6.10）。

**轻篇不支持 / 不是：**

- 代运营公司的合同、报价、回款、销售 CRM；
- 以「代运营业务管理」为中心的产品形态；
- 将产品定义为「帮运营公司管客户」的管理系统。

**概括：** 多品牌是**内容营销工作台**的多租户 / 多品牌能力，不是代运营 ERP。
