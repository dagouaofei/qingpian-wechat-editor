## 核心用户

- 高频公众号运营者
- 企业新媒体
- 教育培训机构
- 知识付费团队
- 本地服务机构
- 个人 IP / 专家型公众号运营者
- 有公众号内容发布需求的中小商家

## 核心场景

1. **输入主题，生成公众号文章** — 用户给出主题，系统生成完整文章
2. **粘贴资料，生成公众号文章** — 用户提供参考资料，系统整理并生成
3. **粘贴草稿，优化并排版** — 用户提供初稿，系统优化结构与排版
4. **生成后预览、少量调整，并复制到微信公众号编辑器** — 预览确认后一键复制

## 第一阶段做

- 主题 / 资料 / 草稿输入
- 结构化文章生成
- 自动排版（正式样式系统）
- 公众号效果预览
- 基础流式 / 打字机式展示
- 微信兼容 HTML 复制
- 微信公众号粘贴效果一致性（P0）
- 配图位置 / image_placeholder
- 样式系统基础架构

## 第一阶段不做

- 多平台发布
- 自动发布到公众号后台
- 团队协作
- 完整 CMS
- 完整样式市场
- 135 / 秀米完整样式导入
- AI 生图
- 图库搜索
- 图片上传
- 文件上传
- 链接读取
- 联网搜索
- 会员 / 支付系统
